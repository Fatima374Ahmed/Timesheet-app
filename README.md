## 📌 Project Overview

This is a React + TypeScript application built using Vite.  
It is a fast, modern frontend setup with Hot Module Replacement (HMR) and ESLint for code quality.

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- ESLint
